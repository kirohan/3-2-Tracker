# Update your existing GitHub repository

1. Extract this ZIP.
2. Copy all extracted files into your existing attendance-tracker repository folder.
3. Replace the old files when Windows asks.
4. Do **not** delete the hidden `.git` folder in your existing repo.
5. In GitHub Desktop, review the changes.
6. Commit with a message such as `Connect live Google Sheet and redesign tracker`.
7. Click **Push origin**.
8. After GitHub Pages redeploys, refresh the site with `Ctrl + F5`.
