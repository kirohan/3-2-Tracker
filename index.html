CORE FEATURES

Simple enough for daily use, complete enough for the whole semester.

The tracker focuses only on the information BECM 2K22 students need to maintain consistently.

01

Class-by-class attendance

Use one dropdown per class to select Attended, Missed or Cancelled. Unmarked rows remain neutral until you update them.

02

Course-wise dashboard

Review attendance percentages, held classes, missed classes, eligibility status and remaining margin by course.

03

Extra and make-up classes

Record additional classes without affecting the regular routine structure. They are included in the final attendance calculation.

04

Spot test and CT records

Log quiz, spot-test and CT information beside the class where it occurred, then summarize teacher-wise performance.

05

60% eligibility tracking

The dashboard uses the 60% attendance requirement and shows whether the current record is above or below the threshold.

06

Holiday-aware schedule

Academic closures can be recorded so scheduled classes on those dates do not distort the attendance statistics.

HOW TO USE

A practical workflow for the semester.

1

Create your personal copy

Click Track with Google and use Google’s own copy screen, or download the Excel file for offline use.

2

Set sessional options

Select the revised sessional slots (effective 27 Sep 2026) and the BECM 3200 odd/even-week cycle for your routine.

3

Update after each class

Mark the class as Attended, Missed or Cancelled. This is the only regular action required.

4

Record tests when needed

If a teacher takes a spot test, quiz or CT, enter the details on the corresponding class row.

5

Check the dashboard

Use the dashboard to monitor course percentages, eligibility status and teacher-wise CT progress.

QUICK NOTES

Common questions

Will a cancelled class reduce attendance?

No. Cancelled classes are excluded from the number of held classes.

Does the Google button download Excel?

No. Track with Google opens the online copy workflow. Download Excel remains a separate option.

Can the tracker be used on phone and laptop?

Yes. Google Sheets is suitable for multi-device use, while Excel is available for offline access.
